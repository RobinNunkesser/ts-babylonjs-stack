Didaktik: Triviale Mechanik vs. 3D-Bühne

🎯 Die didaktische Leitfrage

„Wie viel visuelle Faszination lässt sich aus einer fast trivialen mathematischen Grundregel erzeugen?“

In Vorlesungen über Computergrafik und Spieleentwicklung vermutet man hinter fesselnden 3D-Erlebnissen oft komplexe Physiksimulationen oder kilometerlangen Code. Stack 3D beweist das Gegenteil:

📐 Der 1D-Schnitt: Der gesamte Code-Kern (~20 Zeilen)

// Berechne nur den Versatz auf einer einzigen Achse (X oder Z):
const delta = currentPos - prevPos;
const absDelta = Math.abs(delta);

if (absDelta <= TOLERANCE) {
  // 1. PERFEKT: Einrasten & Pentatonik-Akkord
} else if (absDelta >= currentDimension) {
  // 2. VERFEHLT: Block stürzt ab -> Game Over
} else {
  // 3. SCHNITT: Neuer Quader + fallender Rest
  const overlapSize = currentDimension - absDelta;
  const overlapCenter = prevPos + (delta / 2);
  const cutSize = absDelta; // fällt mit Physik-Drehung
}

✨ Die Babylon.js „Täuschung“ (Rich 3D Visuals)

  • Kaskadierende PBR-Schlagschatten: Der ShadowGenerator lässt jeden neuen Quader weiche Schatten auf die darunterliegenden Schichten werfen.
  • Prozedurales Farb-Changiieren: Jede Ebene wandert im HSL-Farbraum (z. B. HSHL-Blau zu Sonnengelb).
  • Physikalisches Trümmer-Spektakel: Die abgetrennten Scheiben erhalten Schwerkraft und Taumeldrehungen.
  • Sanfte Kamerafahrt: Die isometrische Kamera gleitet mit gedämpfter Interpolation in den Himmel.
  • Pentatonischer Glockenklang: Aufsteigende Melodieläufe bei fehlerfreiem Stapeln erzeugen Dopamin wie in Ketchapp Stack oder Monument Valley.
